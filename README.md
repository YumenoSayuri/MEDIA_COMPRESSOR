# 本地媒体压缩器（图片 + EchoWave 视频）

- 图片：Sharp 本地处理。
- 视频：Electron 后台 BrowserWindow 实际调用 `https://echowave.io/app/tools/compress`，不使用本地 FFmpeg。

## 视频任务

- 基础方案：轻度、平衡、激进、最大化。
- 高级方案：CRF、分辨率、帧率。
- 视频编码器和音频编码器独立于基础/高级压缩模式，两个模式都可以生效。
- 最多同时运行 2 个隐藏 EchoWave 页面，后续任务自动排队。
- 压缩运行中仍可继续选择视频、导入文件夹或拖放文件，新任务会追加到当前队列末尾，不会增加网页并发数。
- 上传阶段同步显示上传百分比和已上传大小；上传速度与预计剩余时间由本项目根据连续上传样本计算。
- 上传进度采用单调高水位记录。EchoWave 在分片切换或上传最终确认阶段即使把网页数字从 100% 暂时改回较小值，本地列表也不会倒退。
- 网页压缩阶段同步读取 EchoWave 的压缩百分比，并显示当前阶段耗时。
- 连续 5 分钟网页压缩仍为 0% 时显示“疑似卡住”；连续 10 分钟仍低于 1% 时自动结束该次尝试。已经出现进度后若连续 20 分钟不再增长，也会按卡死处理。
- 压缩完成后自动下载，并按上传文件的原文件名保存；任务行显示总耗时，不修改结果文件名。
- 应用会拦截 EchoWave 的下载和下载弹出页，直接设置临时保存路径，避免出现系统“另存为”窗口。

## 失败与重试

- 除“已完成”和已从列表移除的任务外，排队、上传、网页压缩、下载、失败、停止等状态都会显示 **重试** 按钮。
- 批量任务运行中点击重试，会立即取消该任务的旧隐藏页面，并把同一文件作为新尝试追加到当前队列末尾；旧尝试不会继续占住两个并发槽位之一，也不会污染最终完成统计。
- 可勾选 **失败后自动重试**，并设置自动重试次数（0–5 次）。总尝试次数等于首次尝试加自动重试次数。
- 自动重试用于打开 EchoWave 页面、上传、网页压缩和下载阶段失败。网页压缩 0% 卡死或长时间无增长时，也会按设置次数重新建立页面任务。
- 下载触发失败时会先在当前页面内自动重新触发下载，仍失败时再按设置次数重新建立页面任务。
- 自动重试开关和次数会与其他视频设置一起持久化，重新启动应用后继续保留。

## 保存方式

1. **源路径保存副本**：`原文件名-副本.ext`，重名自动递增。
2. **固定输出路径**：保存到指定目录，导入文件夹时保留相对目录结构。
3. **直接替换原文件**：先写入临时文件，下载完成后再替换原文件，避免中途损坏源文件。

## 暂停、停止与移除

- **暂停队列**：不再启动排队中的新任务；已经提交到 EchoWave 的远程任务继续运行。
- **停止全部**：关闭当前正在运行的后台 EchoWave 页面并取消下载；未开始的任务保留为“待处理”，不会伪装成“已停止 100%”。再次开始时，所有未完成任务会立即重置为排队状态。
- **移除**：每一行任务都可以随时移除，包括运行中、暂停中和停止过程中。移除运行中任务会取消对应页面/下载；移除排队任务不会启动它。

## 设置持久化

视频的基础/高级模式、压缩方案、CRF、分辨率、帧率、视频/音频编码器、保存方式、固定输出路径、自动重试开关及次数都会保存。

## 运行

```powershell
npm install
npm start
```

默认隐藏 EchoWave 页面。需要查看页面或处理登录/验证码时：

```powershell
$env:ECHOWAVE_SHOW_BROWSER='1'
npm start
```

登录状态保存在 Electron 持久分区 `persist:echowave-video` 中。
